PDF转换器 - 使用说明
================================================================================

项目位置: e:\mining\mining_proxy\pdf-converter

现在提供两个版本：
  ✓ 免费本地版（无需API密钥）
  ✓ CloudConvert API版（付费，质量更高）


快速开始 - 免费版本（推荐）
--------------------------------------------------------------------------------

方式1: 一键启动（最简单）
  双击运行: start-free.bat

方式2: 手动启动
  1. cd e:\mining\mining_proxy\pdf-converter
  2. copy package-free.json package.json
  3. npm install
  4. npm start

然后打开浏览器访问 http://localhost:3000


快速开始 - API版本
--------------------------------------------------------------------------------

方式1: 本地运行
  1. 双击运行 start.bat
  2. 打开浏览器访问 http://localhost:3000

方式2: Docker部署
  1. 确保已安装Docker Desktop
  2. 双击运行 start-docker.bat
  3. 打开浏览器访问 http://localhost:3000


功能特点
--------------------------------------------------------------------------------

✓ 支持拖放上传PDF文件
✓ PDF转Word (DOCX) 格式
✓ PDF转JPG图片格式
✓ 进度条显示转换状态
✓ 支持Docker容器化部署
✓ 响应式设计，支持移动端


版本对比
--------------------------------------------------------------------------------

免费本地版:
  - 完全免费，无需付费
  - 无需API密钥
  - 文件大小限制: 50MB
  - 本地处理，更安全

CloudConvert API版:
  - 需要付费（$9/月起）
  - 需要配置API密钥
  - 文件大小限制: 10MB
  - 专业级转换质量


API配置（仅API版本需要）
--------------------------------------------------------------------------------

1. 访问 https://cloudconvert.com/api/v2 注册账户
2. 获取API密钥
3. 创建 .env 文件（复制 .env.example）
4. 添加 CLOUDCONVERT_API_KEY=你的密钥

注意: CloudConvert不是完全免费的！
  - 免费额度: 25分钟/天
  - PDF转Word: 4积分/次
  - PDF转JPG: 1积分/次

详细说明请查看: CloudConvert_API使用指南.md


免费替代方案
--------------------------------------------------------------------------------

如果不想使用付费API，可以：

1. 使用免费本地版（推荐）
   - 运行 start-free.bat
   - 完全免费，无需配置

2. 自建转换服务
   - 使用LibreOffice命令行

详细说明请查看: 免费版本使用指南.md

常用命令
--------------------------------------------------------------------------------

# 本地运行
npm install
npm start

# Docker部署
docker-compose up -d
docker-compose logs -f
docker-compose down


故障排除
--------------------------------------------------------------------------------

问题: 端口3000被占用
解决: 修改 .env 文件，设置 PORT=3001，然后更新 docker-compose.yml 中的端口映射

问题: Docker构建失败
解决: 确保Docker Desktop正在运行，然后重新执行 start-docker.bat

问题: 转换失败
解决: 检查是否配置了CloudConvert API密钥，查看服务器日志获取详细信息
